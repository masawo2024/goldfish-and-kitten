# 金魚鉢と黒猫の子猫 (Goldfish Bowl & Black Kitten)

透明なガラスの金魚鉢の中を泳ぐ3匹の立体的な金魚と、その隣に座って狙っている黒猫の子猫を描いたインタラクティブな HTML5 Canvas アニメーションです。

## ライブデモ (GitHub Pages)

- メイン版（金魚鉢と黒猫の子猫）: https://masawo2024.github.io/goldfish-and-kitten/
- 別バージョン（`goldfish_kitten.html` / 金魚鉢と黒い子猫）: https://masawo2024.github.io/goldfish-and-kitten/goldfish_kitten.html

## 特徴

- **3D 立体メッシュの金魚（3匹）**
  - 更紗琉金（紅白）・黄金琉金・丹頂（白地に赤い肉瘤）の3種類が、球面の金魚鉢の中を奥行きを持って泳ぎます。
  - 側扁した金魚らしいフォルム、Blinn-Phong ライティング、水中からの照り返し光、大きくパクパク動く口、透け感のある四ツ尾や胸びれを描画しています。
- **黒猫の子猫のアクション**
  - 金魚の動きに合わせて琥珀色の瞳や頭の傾きが追従し、近づいた金魚を狙って前足（肉球つき）でガラスを「ちょいちょい」と叩きます。
- **透明な金魚鉢と光・水の表現**
  - ガラスの反射、揺れる水面と気泡、テーブルに映る水面の屈折光（コースティクス）を表現しています。
- **インタラクション**
  - **金魚鉢の上部をクリック / 「エサをあげる」**: 水面にエサを落とし、金魚が集まって食べます。
  - **金魚鉢の側面をクリック**: ガラスを叩いて金魚を驚かせます。
  - **黒猫をクリック / 「黒猫がちょいちょい」**: 子猫がガラスをちょいちょいします。
  - **「時間帯」ボタン**: 昼・夕方・夜の3つのライティングを切り替えられます。

## ファイル構成

- `index.html` — GitHub Pages 公開用エントリーポイント
- `goldfish_and_kitten.html` — 単体 HTML アニメーション本体（外部ライブラリ不要）
- `goldfish_kitten.html` — 別バージョン（金魚鉢と黒い子猫）
- `README.md` — このドキュメント

## ローカルでの実行方法

外部ライブラリやビルド手順は不要です。`index.html` または `goldfish_and_kitten.html` をそのままブラウザで開くだけで動作します。
